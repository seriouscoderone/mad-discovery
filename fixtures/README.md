# Fixtures

Outside vectors for the tests. No file here is produced by the code under test. `make.sh` makes them all except the TLS pair, made once by the command given below; the results are committed as binary (`.gitattributes`: `-text`) and never formatted. A compact fixture has no final newline. The makers record where every vector came from and were run once on the maintainer's machine, with bpm-core's and keripy's interpreters and two downloads; they are not expected to run elsewhere, and need not: a frozen document cannot drift from its SAID, so the committed copies stay valid.

- `compact/<SAID>.json`: bytes that verify against the SAID in the file name. 28 are gym-bp's frozen documents, written compactly by bpm-core's own serializer from a clean `rebuild.sh`. One is GLEIF's Qualified vLEI Issuer schema exactly as served from `www.gleif.org`. Two were written by keripy 2.1.0.dev0 (Apache-2.0): an inception event whose SAID is in both `d` and `i`, and a schema with non-ASCII text. Five were saidified by bpm-core and hold values Node's JSON round trip would change. One was constructed so that its SAID is directly followed by `#`.
- `pretty/<SAID>.json`: the same documents pretty-printed. 28 are gym-bp's store files as stored. One is the vLEI repository's copy of GLEIF's schema (`WebOfTrust/vLEI`, Apache-2.0, `schema/acdc/qualified-vLEI-issuer-vLEI-credential.json`, commit 6e1a33ddbf1537d1c7e12dc0dae409c2a58ffafa), whose bytes with whitespace removed equal what GLEIF serves.
- `refused/`: two honest documents whose content holds 44 and 50 consecutive `#`; the check cannot tell their SAID slot from their content and refuses them. `index.json` names their SAIDs.
- `gym-config.json`: a configuration that serves gym-bp's three selections, each with a publication. gym-bp's documents carry no description, so these are hand-written.
- `ai-catalog/example-6e26a18.json`: the AI Catalog specification's own example catalog, `specification/examples/ai-catalog.json` at commit `6e26a18` (2026-11-05) of `github.com/Agent-Card/ai-catalog`, whose split license puts machine-readable assets under Apache-2.0 and the specification text under CC BY 4.0. The checker in `tests/aicatalog.test.ts` must accept it before it judges the build's output.
- `tls/cert.pem`, `tls/key.pem`: a self-signed certificate for 127.0.0.1, made once with `openssl req -x509 -newkey rsa:2048 -nodes -days 36500 -subj "/CN=mad-discovery test" -addext "subjectAltName=IP:127.0.0.1"`. Nothing trusts it: the tests use it to show that the fetch routine refuses a certificate no authority signed, with or without `NODE_TLS_REJECT_UNAUTHORIZED=0` in the environment. The private key is public by design and protects nothing.
